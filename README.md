# ذكرى ميلاد سندس

موقع تهنئة عربي ثابت، يتضمن رسالة عيد ميلاد ومعرض صور ومشهد كعكة تفاعليًا ثلاثي الأبعاد.

## النشر على GitHub Pages

1. ارفع ملفات المشروع إلى مستودع GitHub على الفرع `main`.
2. من **Settings → Pages**، اختر **GitHub Actions** كمصدر للنشر.
3. سيُنشر الموقع تلقائيًا عند كل تحديث للفرع `main`. ويمكن بدء النشر يدويًا من تبويب **Actions**.

ملفات الصور (`photo-1.png` إلى `photo-4.png`) يجب أن تبقى بجانب `index.html`.

## التشغيل

افتح `index.html` في المتصفح أو استخدم خادم ملفات محليًا. يعتمد تحميل الخطوط وTailwind CSS وThree.js على الاتصال بالإنترنت.
